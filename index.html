Limites desta versão

PDF e DOCX usam bibliotecas carregadas pela internet (PDF.js e Mammoth). OCR usa Tesseract.js. É necessário estar online na primeira utilização dessas ferramentas. Arquivos de áudio/vídeo ficam guardados localmente como anexos; a transcrição automática depende de suporte de reconhecimento de voz do navegador e não é garantida. Para transcrever qualquer arquivo de mídia, será necessária uma API de transcrição numa próxima etapa.

Portabilidade e segurança

O backup JSON permite migrar a biblioteca. Os anexos são guardados no Storage quando a nuvem está conectada. Nunca armazene senhas, chaves privadas ou dados pessoais sensíveis em conhecimentos compartilhados.
